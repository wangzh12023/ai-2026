# 图标来源

以下均为下载后保存的资产，未重绘路径、添加装饰或重新配色。SVG 是矢量格式，可在高 DPI 屏幕无损显示。

| 文件 | 来源 | 用途 |
| --- | --- | --- |
| openclaw-official.svg | [OpenClaw 官网](https://openclaw.ai/) 的 [mascot 原文件](https://openclaw.ai/brand/openclaw-mascot.svg) | OpenClaw 主事件；替换原 Lobe Icons 版本 |
| unitree-official.svg | [宇树官网](https://www.unitree.com/) 白色导航状态使用的 [原始 Logo](https://www.unitree.com/images/0079f8938336436e955ea3a98c4e1e59.svg) | 宇树上市事件 |
| material-policy.svg | [Google Material Symbols / policy](https://github.com/google/material-design-icons/blob/master/symbols/web/policy/materialsymbolsrounded/policy_48px.svg)，Apache 2.0 | 拟人化互动监管事件的语义图标；不是该法规或国家网信办的官方 Logo |
| europe.svg | [Wikimedia / Flag of Europe](https://commons.wikimedia.org/wiki/File:Flag_of_Europe.svg) | 欧盟 AI Act 事件；标准欧洲旗 |
| 其他品牌 SVG | [Lobe Icons](https://github.com/lobehub/lobe-icons)（MIT）、[Simple Icons](https://simpleicons.org/)（CC0） | 其余品牌标识 |

Google 图标许可证在 MATERIAL-SYMBOLS-LICENSE.txt；Lobe Icons 许可证在 LOBE-ICONS-LICENSE.txt。品牌及旗帜标识仍属于各自权利人，不表示本站获得其背书。

复现下载：项目根目录执行 `node scripts/fetch-icons.mjs`。现有图标库提取：`node scripts/icons.mjs`。
