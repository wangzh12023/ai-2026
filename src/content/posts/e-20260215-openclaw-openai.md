## 顶流开源黑客的“闪电招安”

2026 年 2 月 15 日，在个人常驻智能体 OpenClaw 发布并席卷全球开发者生态仅仅半个月后，OpenAI 首席执行官 Sam Altman 在 X 上抛出了一枚震撼行业的人才重磅炸弹：OpenClaw 的缔造者 Peter Steinberger 正式入职 OpenAI，领衔组建并负责 OpenAI 内部的“下一代个人常驻智能体（Next-Generation Personal Agents）”核心研发团队。

Peter Steinberger 是全球极客社区公认的传奇工程老兵。早在他打造出风靡一时的 PDFKit 并将其成功出售之前，他便以极度强悍的跨平台原生工程架构、系统级底层钩子（Hooks）设计和对开发者痛点的极致嗅觉闻名。当他用短短几个月业余时间拼装出的 OpenClaw 轻易撕开大厂重兵把守的 Agent 入口并掀起全球装机狂潮时，硅谷的所有巨头（包括微软、Meta、Google 与 OpenAI）几乎在同一时间向他抛去了橄榄枝。

```
                    ┌── [Peter Steinberger 本人] ──> 入职 OpenAI 领衔 Next-Gen Personal Agents
                    │                                (技术路线直接孕育了秋季发布的 dots)
[OpenClaw 爆红破局] ─┤
                    │
                    └── [OpenClaw 项目本身] ───────> 剥离成立独立 OpenClaw Foundation
                                                     (由社区接管，OpenAI 承诺资金与算力资助)
```

## 妥协与范式：“人去壳留”的基金会治理结构

大厂收割爆款开源项目的创始人，在科技史上往往伴随着开源项目的迅速窒息、代码库闭源私有化或社区愤而硬分叉（Hard Fork）。然而在这一次的人才收购案中，双方展现出了极其精妙的商业与社区平衡术：

1. **项目法律实体彻底剥离**：Peter Steinberger 并没有将 OpenClaw 的知识产权（IP）整体出售给 OpenAI，而是在入职前夕将代码库的所有权无偿捐赠给全新注册的独立非营利组织 **OpenClaw Foundation**。项目依然完全保留 Apache 2.0 宽松开源许可，日常合并权限由长期活跃的数位核心社区贡献者接管。
2. **OpenAI 的资金与生态背书**：OpenAI 官方宣布成为该开源基金会的首任白金赞助商，承诺提供数百万美元的专项开发资金及长期的云端推理 API 额度补贴，并公开承诺“绝不干预、绝不限制 OpenClaw 对 Anthropic、Google、DeepSeek 等竞品模型接口的原生支持”。
3. **OpenAI 内部战线的实质性转向**：在吸纳 Peter Steinberger 之后，OpenAI 内部原本偏向于网页端 ChatGPT 插件与临时沙箱的 Agent 探索被迅速重构。Peter 带来的“系统底层常驻、异步事件轮询、轻量级硬件载体友好”的核心设计哲学，直接成为了 OpenAI 随后在 9 月开发者大会上亮相的常驻桌面智能体 **dots** 的技术基石。

## 巨头争夺的余波与开源生态的现实

这场闪电入职在开源黑客文化与大厂资本之间激起了长达数月的哲学激辩：

- **理想主义者的叹息与现实主义者的认同**：一部分倡导绝对技术自治的开发者对 Peter 在项目刚破圈时便“倒向大厂”表达了尖锐的批评，认为大厂正在利用雄厚的资本与算力储备对开源民间力量实施“摘桃子”式的虹吸；然而更多务实的工程师则认为，“人走核心团队、壳留开源社区”不仅让创作者获得了应有的财富与顶级研发资源，更保全了开源项目的生命线，是当下时代顶级开源作者最理智的归宿。
- **扎克伯格的错失与后手**：据知情人士透露，在 Altman 敲定协议前 48 小时，Meta 掌门人扎克伯格曾亲自视频通话邀请 Peter 加盟，试图为其当时的 Llama 体系补上最欠缺的常驻操作系统层。在痛失 Peter 后，Meta 迅速转变策略，于三周后闪电收购了依托 OpenClaw 诞生的智能体社交网络 **MoltBook**，直接买下了智能体互动的应用层。

这场“人去壳留”的经典收编，不仅重新划定了 2026 年个人常驻 Agent 的技术版图，也揭开了全球大厂针对顶级 Agent 架构师争夺战的序幕。
